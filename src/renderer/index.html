Conexão com o painel
Cole aqui o endereço base do seu painel — sem /admin no final.
Exemplo: se você acessa https://alinhafood.com.br/admin, coloque só https://alinhafood.com.br
Gerado em Admin → Impressora → Agente de Impressão → "Gerar token"
Impressora
Em dúvida, deixe "Epson / Genérica" — funciona com 90% das impressoras de cupom
Impressora instalada no Windows: clique em "Detectar impressoras" para listar filas USB e Bluetooth já pareadas.
Para Bluetooth, primeiro pareie a impressora no Windows e confirme que ela aparece em Dispositivos e Impressoras.
Use "Testar impressora" para confirmar se a fila selecionada aceita ESC/POS RAW
Bluetooth Serial: use quando a impressora pareada cria uma porta COM, mas não aparece como impressora instalada no Windows.
A velocidade mais comum é 9600. Se não imprimir, teste 19200, 38400, 57600 ou 115200.
IP da impressora: verifique na tela da impressora ou no roteador.
A porta padrão é 9100 — use o formato 192.168.1.100:9100
Use exatamente o mesmo nome que aparece em Painel de Controle → Dispositivos e Impressoras.
Para USB ou Bluetooth com driver instalado, o agente envia pela fila de impressão usando este nome.
No modo Bluetooth Serial, este campo é opcional.
